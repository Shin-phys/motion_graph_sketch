# 描いてわかる運動グラフ

指で描いたグラフを台車の運動に変え、指で動かした運動をグラフに変えて、**x-t・v-t・a-t グラフの相互変換**を身につける高校物理（物理基礎「運動の表し方」）のアプリです。
インストール・ログイン不要で、スマートフォン・Chromebook・PCのブラウザで動きます。進み具合は端末の中だけに保存し、外部には何も送りません。

- 公開URL: https://shin-phys.github.io/motion_graph_sketch/
- 仕様メモ: [docs/spec/README.md](docs/spec/README.md)

## 4つのモード

| モード | 生徒がすること | URL |
| --- | --- | --- |
| ステップ学習 | 8つのステップを順に進める（操作課題 → 気づきを3択でえらぶ）。約25分 | `?mode=steps&step=3` |
| グラフ → 運動（つくる） | x-t か v-t を描いて再生し、台車の動きと残りのグラフを確かめる。お題つき | `?mode=draw` |
| 運動 → グラフ（動かす） | 台車を指で動かして記録し、グラフにする。お手本に重ねる「グラフ合わせ」で点数を出す | `?mode=drag` |
| 予想チャレンジ | 運動やグラフを1つ見て、別のグラフを予想して描いてから答え合わせ（16問） | `?mode=predict&id=p05` |

`&big=1` を付けると、文字が大きい投影モードになります。

## 設計の考え方

- **予想してから確かめる**：正解のグラフは、予想を描き終える（運動の長さの9割以上）まで、画面のどこにも出しません。答え合わせでは、正解が時間カーソルとともに描かれ、予想（破線）に重なります。
- **1本の時間カーソルで全部がつながる**：台車の位置、3つのグラフ、接線、面積が、いつも同じ時刻を指します。
- **誤答パターンに合わせたヒント**：「元のグラフと同じ形」「向きの無視」「符号が逆」「グラフの種類のとりちがえ」に近い予想には、それぞれ専用のヒントを1文で出します。

## 描き方

- **折れ線**（標準）：タップで点を置き、ドラッグで動かす。長押しで消す（PCではダブルクリック・右クリックでも消せる）。点は 0.5 s きざみ、値は x：0.5 m、v：0.5 m/s きざみに吸着します。**同じ時刻にもう1つ点を置くと、値を一瞬で変えられます**（速度が切り替わる運動）。
- **フリーハンド**：指でなぞる。左へ戻ってなぞると、その時刻から描き直せます。

## 採点

お手本 y\*(t) と生徒の曲線 y(t) を、運動の長さの範囲でくらべます。

得点 = 100 × max(0, 1 − RMSE ÷ (0.4 R))　（R はお手本の最大値と最小値の差。下限 x：2 m、v：1 m/s、a：0.5 m/s²）

70点以上で合格です。係数・下限・合格点などは [src/core/constants.ts](src/core/constants.ts) にまとめてあり、実際に使ってみて調整できます。

## 収録問題

区間ごとに速度または加速度が一定の運動として定義し（[src/data/problems.ts](src/data/problems.ts)）、x・v・a はそこから計算します。

| レベル | 問題 | 出題する変換 |
| --- | --- | --- |
| 1・2（一定の速さ・向きが変わる） | p01〜p08 | 運動→x-t、x-t→v-t、v-t→x-t |
| 3・4（だんだん速く・遅く、折り返し） | p09〜p16 | 運動→v-t、v-t→a-t、v-t→x-t、x-t→v-t |

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # 計算部分のテスト（Vitest）
npm run build   # dist/ に出力
```

計算（曲線の変換・採点・誤答パターン・ドラッグ記録）は `src/core/` に画面から独立した関数として置き、テストしています。
`main` に push すると、GitHub Actions がテスト・ビルドして GitHub Pages に公開します。
