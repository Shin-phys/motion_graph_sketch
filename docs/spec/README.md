# 実装メモ（仕様書との対応）

仕様書は別に管理している「1 描いてわかる運動グラフ 仕様書」。ここには、実装で決めたことと、仕様書からの変更点を記録する。

## 構成

| 場所 | 内容 |
| --- | --- |
| `src/core/constants.ts` | 標本の刻み（0.05 s・201点）、吸着の刻み、採点の係数、平滑化の幅など、調整用の定数 |
| `src/core/curve.ts` | 曲線の表現、折れ線・フリーハンドの標本化、v→x（台形公式）、傾き、ガウス平滑化 |
| `src/core/motion.ts` | 収録問題の定義から x・v・a を解析的に計算 |
| `src/core/score.ts` | 採点、ずれが最も大きい区間 |
| `src/core/patterns.ts` | 誤答パターンの判定 |
| `src/core/record.ts` | ドラッグ記録（再標本化、記録中の表示用フィルター、記録後の計算し直し） |
| `src/data/problems.ts` | 収録問題16問、「つくる」のお題6問 |
| `src/data/steps.ts` | ステップ学習8ステップの内容 |
| `src/ui/` | 画面（Canvas のグラフ・コース、4つのモード） |

## 曲線の表現

- すべての曲線は 0〜10 s を 0.05 s 刻みで標本化した201点の配列。
- 値が一瞬で変わる点（段差）は、その標本に「変わったあとの値」を入れ、別に「変わる直前の値」を持つ（`jumps`）。
  これにより、折れ線の v-t から台形公式で求めた x が解析解と一致し（誤差 1×10⁻⁶ m 未満をテストで確認）、段差は縦の破線で描ける。
- 折れ線で段差を描くには、同じ時刻に節点を2つ置く（仕様書には段差の描き方の記述がなかったため追加）。同じ時刻に置ける節点は2つまで、節点は全部で24個まで。

## 仕様書からの変更・追加

- **段差の前後は採点から外す**：お手本の値が一瞬で変わる時刻の前後 0.25 s は採点に使わない（`JUMP_MARGIN`）。
  速度の切り替わりを斜めの線で描いた答案が、内容は合っているのに不合格になるのを防ぐため。全区間0の答案が30点未満になること、正解が100点になることは変わらない（テストで確認）。
- **運動の終わりの標本**は「直前の値」でくらべる（運動の終わりで線を0に落としても減点しない）。
- **グラフを見て x-t を予想する問題**（v-t→x-t）では、答え合わせまで台車を動かさない。台車の動きがそのまま答えになるため。はじめの位置はグラフ上に●で示し、t = 0 の値は動かせない。
- **ステップ8（総合）**は、p16 の運動を見て x-t・v-t・a-t を順に予想する3問にした（a-t を問う「運動→a-t」はステップ8だけで使う）。
- **ステップ学習の v-t グラフ**には、はじめから t = 0 s と t = 10 s の両方に○を置く。10 s の○は縦にだけ動き、消せない（両はしを上下させるだけで、水平な線・右上がり・右下がりの直線が描けるようにするため）。ほかの点は 10 s の手前に置く。
- **ステップ1・2・5・6の判定**：再生して3秒たった時点で、描いたグラフが課題に合っているかを調べる。合っていなければ、どう直すかを1文で示す。
  「気づき」の3択はグラフの下に出し、再生中に画面がずれたり勝手にスクロールしたりしないようにする（声かけの欄は2行分の高さをあらかじめとっておく）。
- **「つくる」のお題で x-t を描いたとき**は、はじめの位置をそろえて（変位で）判定する。
- **ストロボの足あと**（初版のあとに追加）：再生や時刻つまみに合わせて、1秒ごとの台車の位置をコースの下に点で残す。右へ進むときは上の段、左へ戻るときは下の段に並べ（向きは「その点から次の点へ」で決める）、止まっている間の点は1つにまとめて「8〜10」のように時刻を添える。
  オン・オフは生徒がえらび、えらんだ状態は次の問題にも引き継ぐ。グラフを見て x-t を予想する問題では、足あとが答えそのものになるので、答え合わせまで使えない。段の場所はいつもとっておき、切り替えても画面がずれないようにする。
- **コマ送り**（初版のあとに追加）：再生バーの「−0.5 s」「＋0.5 s」で、0.5 s の区切りへ進める・戻す。
- **小さいグラフの「大きく」ボタン**：仕様書では「小さいグラフをタップすると入れ替わる」としていたが、グラフのタップは時間カーソルの操作に使うため、ボタンにした。
- **グラフ合わせ**では、記録が始まるまで台車をお手本のはじめの位置に固定する。
- スマートフォンでは、画面上部の見出しを固定しない（スクロールしたときにコースを隠さないため）。

## 自動テストで確認していること（`src/core/core.test.ts`）

- 折れ線の v-t から求めた x が、解析解と 1×10⁻⁶ m 以内で一致する（16問）。
- 16問すべてで x が −5〜+5 m に収まり、終わりの x が仕様書の表と一致する。節点が吸着の格子に乗っている。
- 正解そのもの（解析解・折れ線で描いたもの）を入力すると100点になる（全問・全タスク）。
- 全区間0の入力は、16問すべての x-t・v-t で30点未満になる。
- 正解の絶対値を入力すると、負の速度を含む問題（p04〜p08、p12〜p16）の v-t で「向きの無視」と判定される。正解そのものには、どの型も当てはまらない。
- ドラッグ記録：指を止めると、記録中の v の表示が ±0.05 m/s 以内に落ち着く（模擬データ）。

## 実機で確認が必要なこと

- iPhone（Safari、縦持ち）で、描画中に画面がスクロール・拡大・テキスト選択されない。
- 幅360pxの画面で、折れ線の節点を指で狙った格子点に置ける。
- ドラッグ記録の手ざわり（遅れ・ぶれ）と、グラフ合わせの点数の出方。採点の係数などは `constants.ts` で調整する。
- ステップ学習を初見の生徒が説明なしで30分以内に終えられるか。
